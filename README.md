# 住宅物业人员编制配置官

面向物业公司、开发商与物业咨询顾问的**人员编制与人力成本一键测算工具**。
单个 HTML 文件、纯前端、零依赖，手机/电脑浏览器打开即用。

## 功能特性

- **四步录入**：① 面积与数量（总建面、收费面积、绿化面积、户数、出入口、消控室等）② 物业费单价 ③ 项目基本参数（服务等级/班制/入住率）④ 各岗位月人均成本
- **六大岗位自动定编**：客服、秩序、保洁、工程、绿化、管理（项目经理/项目助理/行政人事财务）
- **成本收入实时核算**：月人力成本、月物业费收入、成本占收入比（基准/上限双口径）
- **60% 健康线预警**：人力成本占收入比超 60% 即提示"人力成本有超支风险，请考虑降本方案"
- **100% 强制降级规则**：收入覆盖不了人力成本时，监控岗自动降为每班 1 人并重算总编制
- **完整输出**：各岗位编制明细表（人数/月薪/小计）+ 成本收入汇总 + 分级优化建议

## 快速开始

无需安装、无需构建、无需后端：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：任意静态服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 测算规则

测算口径来源于物业管理行业人员编制实践，完整规则见 [规则知识库.md](规则知识库.md)。
核心口径：

- 客服、收费面积保洁按**区间配置**，基准取区间下限，上限作可选上调参考
- 秩序岗含门岗/监控/巡逻/班长/替休/主管，监控默认每班 2 人（消控室数量×班制系数）
- 管理岗占比约束：项目助理+行政人事/财务 ≤ 总编制×10%，项目经理固定 1 名不参与占比
- 老旧小区秩序主管与保洁主管合并为同一人，只计 1 次

## 技术实现

- 单文件 HTML + 原生 JavaScript，无框架、无后端、无外部网络请求
- 全部计算在浏览器端完成，数据不出本机
- 移动端自适应布局，分步表单 + 缺项校验
